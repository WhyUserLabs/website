Pricing FAQ

Questions about pricing.

01What exactly is a credit?

The unit every run is priced in. A Persona Simulation is 5 credits. A Buyer Intelligence run, a Committee Simulation or an email combo is 20. Buyer Questions Coverage is 10 plus 5 per use case. An ad creative or an Audience Discovery run is 50.

02Do credits expire?

Plan credits expire at the end of each month, so use them in the month you get them. Credit packs do not expire while you are subscribed.

03Why is there no monthly plan?

Plans are annual. If a year is too big a first step, start with the free gap list.

04What happens when I run out of credits?

Nothing auto-charges and nothing breaks. Add a pack at $1,000 for 200 credits, or move up a plan and we credit what you have paid.

05Does a failed or useless run still cost credits?

A run that errors is not charged. If a finished run is unusable, say the wrong page went in, tell us and we return the credits.

06Do we pay per seat?

No. Seats are unlimited on every plan.

07How does this compare to a research panel?

A panel study costs $2,000 to $8,000 and takes hours to weeks. A WhyUser page test costs $25 for a Persona Simulation or $100 for a full Committee Simulation; see the full comparison.

08What does procurement need from us?

Our DPA and security docs are open to read before you send us a URL.

09Can we use WhyUser in Claude, or through an API?

Yes, on every plan. The MCP server brings WhyUser into Claude, Cursor and Codex, and everything you see in the web app is also available over the API. Connect to Claude.
